# Learning Riemannian Geometry on 3D Objects — project website

A dependency-free static project page for GitHub Pages. The design uses a white background, restrained typography, responsive scientific tables, accessible figure lightboxes, qualitative-result tabs, and BibTeX copying.

## Deploy

Copy the contents of this directory to:

`circle-group.github.io/research/LearningReiemannianGeometry/`

All asset links are relative. The included `.nojekyll` file keeps GitHub Pages asset serving predictable.

## Included resources

- `index.html` — project page
- `assets/css/site.css` — responsive layout and print-like scientific styling
- `assets/js/site.js` — mobile navigation, accessible tabs, figure lightbox, BibTeX copying
- `assets/images/` — optimized WebP figures
- `paper.pdf` and `supplementary.pdf` — local PDFs

## Before final publication

- Replace the PDFs if the camera-ready or arXiv versions change.
- Update the BibTeX entry when proceedings page numbers or a DOI are available.
- Add a code link only when a public repository URL is available.
